First beta release of Foraxx Palette for Photoshop.

Build an editable Foraxx narrowband palette from stretched, starless Ha/OIII
or SII/Ha/OIII layers. Includes optional stars, per-channel gains, separate
red/green mask bias and contrast, OIII midtone shaping, a live thumbnail
preview, and an Original Foraxx reset. Outputs ordinary layers and masks in
one undo step, with tiled processing for large images.

## Install

1. Download **foraxx-palette-0.1.0.ccx** below (not the source-code ZIP).
2. Double-click it to open Creative Cloud Desktop and accept the prompt for
   a plugin distributed outside Adobe Marketplace.
3. Open Photoshop and choose **Plugins > Foraxx Palette**.

Developer Mode and a signing certificate are not required. This is an
independently distributed UXP plugin, packaged with Adobe's UXP tooling.
`SHA256SUMS.txt` provides the installer checksum.

## Compatibility and validation

- Requires an 8- or 16-bit RGB document with full-canvas source layers.
- Validated on Windows with Photoshop 2026 (27.10.0). The manifest permits
  Photoshop 24.4 or newer; older versions and macOS have not been tested.
- 13 math tests, 16 Photoshop build checks, and 5 preview checks passed.
- Adobe's installer successfully installed the release CCX and reports
  Foraxx Palette 0.1.0 enabled for Photoshop 27.10.
- A 12174 × 7952 narrowband example was checked at full resolution against
  the original formula, with maximum error below one 16-bit storage step.

## Beta limitations

- 32-bit documents are not supported because the layer stack requires Screen.
- Preview uses sampled inputs; fine detail can differ from the full build.
- Existing output groups do not update when settings or sources change;
  build a new group to apply them. Refresh the preview after source edits.
- One Photoshop crash occurred during repeated development reloads and a
  native picker check. Its cause is unresolved; subsequent host tests passed.

See the [README](https://github.com/theatrus/foraxx-photoshop/blob/v0.1.0/README.md)
for usage and palette controls. Report problems through
[GitHub Issues](https://github.com/theatrus/foraxx-photoshop/issues), including
Photoshop version, OS, document depth and reproduction steps.
