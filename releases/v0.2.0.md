Foraxx Palette 0.2.0 beta adds more palette controls and FPU-inspired color finishing, with support for wider RGB working spaces.

## What's new

- **Mask blur:** smooth the dynamic mixing masks with adjustable Gaussian blur while preserving detail in the color layers.
- **More palettes and shaping:** static SHO, HOO, HSO and OHS mappings, plus independent Ha, OIII and SII midtone controls.
- **Color finishing:** Lab chroma noise reduction, FPU hue/saturation curves, background protection, protected saturation boost and L* lift.
- **Wide-gamut support:** finishing uses the document's sRGB, Adobe RGB (1998), Display P3/image P3 or ProPhoto RGB profile. Output stays in that working space; the panel thumbnail is converted to sRGB for display.
- **Reusable masks:** export mixing factors, channel ratios and the protected saturation mask.
- **Preview and workflow:** result, stars and mask views; zoom and pan; manual or live updates; remembered settings; and separate or combined stars.

Original Foraxx resets all optional processing to neutral. Color finishing creates clearly labeled snapshot layers above the editable raw palette stack.

## Install or update

1. Download **foraxx-palette-0.2.0.ccx** below (not the source-code ZIP).
2. Double-click it and follow the installation/update prompts in Creative Cloud Desktop.
3. Open Photoshop and choose **Plugins > Foraxx Palette**. Reopen the panel if it was already open.

Developer Mode is not required. `SHA256SUMS.txt` provides the installer checksum.

## Compatibility and validation

- Requires an 8- or 16-bit RGB document with full-canvas source layers. Use 16 bits for wide-gamut editing.
- Validated on Windows with Photoshop 2026 (27.10.0). The manifest permits Photoshop 24.4 or newer; older versions and macOS have not been tested.
- All 31 automated tests passed. Local Photoshop checks covered mask blur, additional palettes, finishing, reusable masks, preview agreement, strip boundaries, merging and undo.
- Eight profile-specific build checks passed across the four supported RGB spaces at 8 and 16 bits. Color-patch conversions also matched Photoshop's Lab readings within one 8-bit Lab step.

## Beta limitations

- 32-bit documents are not supported because the layer stack requires Screen.
- Custom or untagged profiles require color finishing to be disabled.
- FPU controls are adaptations; results are not guaranteed to be pixel-identical to PixInsight's native processing.
- Preview uses sampled or cropped inputs. Fine detail and crop edges can differ from the full build; use Photoshop's canvas to judge wide-gamut colors.
- Existing output groups and processed snapshots do not update automatically. Rebuild after changing inputs or settings; hide the snapshot to edit the underlying raw stack.

See the [README](https://github.com/theatrus/foraxx-photoshop/blob/v0.2.0/README.md) for usage and palette controls. Report problems through [GitHub Issues](https://github.com/theatrus/foraxx-photoshop/issues), including Photoshop version, OS, document depth/profile and reproduction steps.
